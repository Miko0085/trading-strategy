# История изменений документации

## 2026-09-19

- Русский язык закреплён как основной язык публичной документации.
- Навигация GitBook переведена на русский.
- Добавлены русские определения технических терминов.
- `original_qty` заменяется в пользовательском смысле на `configured_qty` — заданный трейдером объём.
- Уточнено, что несколько fills одного Grid Order остаются одним логическим ордером.
- Зафиксировано: Strategy Lot создаётся после полного исполнения `configured_qty`.
- Take Profit не активируется до полного исполнения Grid Order.
- Зафиксировано зеркальное построение первого Long/Short уровня относительно Mark Price.
- Добавлено разделение GridOrderState / StrategyLotState / TPStepState.
- Добавлена обязательная история Grid Revision.
- Добавлена политика реакции на ручное вмешательство через терминал Bybit: уведомить → подтвердить → принять или восстановить.
- Убрана лишняя привязка публичной документации к одному конкретному активу и короткому периоду наблюдений.
