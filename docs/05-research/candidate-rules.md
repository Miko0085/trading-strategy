# Candidate Rules

**Статус: CANDIDATE** — гипотезы, требуют повторных наблюдений и/или подтверждения трейдера. Ничего в этом файле не является `CONFIRMED`.

## 1. Глубина Long-сетки ≈ -30% от цены входа

Источник: note #7 (verified) + уточнение в чате. Проверка на данных:

- Цикл 1: глубочайший уровень -29.3% от входа — близко совпадает.
- Цикл 2: глубочайший уровень -41.2% от входа — не совпадает.

Статус понижен до `CANDIDATE` (не `CONFIRMED`) из-за расхождения — см. [contradictions.md](contradictions.md).

## 2. Объём растёт глубже по сетке

Наблюдалось качественно в обеих известных Long-сетках (151→174→299 и 147→185→350), но множитель между шагами непостоянный (~1.15×/1.72× и ~1.26×/1.89×). **Не фиксировать** `qty × 2` или любой другой множитель как правило.

## 3. Полное закрытие → немедленное открытие нового цикла

Наблюдалось один раз (закрытие цикла 1 → открытие цикла 2 через ~1 минуту). Одно наблюдение недостаточно для повышения статуса.

## 4. Partial unloading для фиксации PnL и высвобождения margin

Мотив объяснён трейдером в общем виде (см. [01-strategy/partial-take-profit.md](../01-strategy/partial-take-profit.md), исторический пример ETH Short), но ни разу не наблюдался как частичное (не полное) закрытие в текущем dataset.

## 5. Положительный uPnL одной стороны влияет на решения по другой

Из исходного описания проекта, ни разу не подтверждено на данных и не объяснено трейдером. См. [open-questions.md](open-questions.md), вопрос 11.
