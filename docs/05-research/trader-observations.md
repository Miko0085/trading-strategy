# Наблюдения трейдера

**Статус: НАБЛЮДАЕМЫЕ ФАКТЫ + ОБЪЯСНЕНИЯ ТРЕЙДЕРА**

## Подтверждено прямым объяснением

- Grid Geometry и Sizing — разные механизмы.
- Относительные расстояния текущей сетки должны сохраняться.
- Future qty должны пересчитываться при изменении factual/capital state.
- Allocation Long/Short/Reserve применяется при каждом перерасчёте.
- Partial fill считается нормальным.
- TP рассчитывается от реально набранного объёма.
- Pending grid может двигаться за ценой, сохраняя geometry.
- Position Mode проверяется отдельно для каждого symbol.

## Наблюдения по фактической торговле 13–20 сентября 2026

Наиболее полная выборка — LSKUSDT.

Наблюдается:
- последовательное увеличение объёма на более глубоких ценах;
- повторяющиеся встречные partial executions после глубоких входов;
- повторный набор после последующего движения цены;
- существенная динамика inventory;
- реализация tail-risk при сильном движении.

Эти факты подтверждают необходимость lot-level accounting и account-level risk, но сами по себе не доказывают точную формулу Martingale/TP/recovery.

## Исправление старой формулировки

StrategyLot появляется после первого фактического fill, а не только после полного исполнения configured_qty.
