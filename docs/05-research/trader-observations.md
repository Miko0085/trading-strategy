# Trader Observations

**Статус: OBSERVED FACT + TRADER EXPLANATION**

Публичная страница содержит только обобщённые наблюдения. Реальные order IDs, raw trade history, приватные wallet/account данные и voice-файлы здесь не публикуются.

## Что уже наблюдается/объяснено

- трейдер использует Hedge Mode;
- Long и Short могут существовать одновременно;
- используются лимитные Grid Orders;
- параметры разных уровней могут различаться;
- более глубокий уровень может иметь больший quantity;
- отдельный исполненный уровень важно рассматривать отдельно от агрегированной average price позиции;
- частичная разгрузка используется как механизм фиксации прибыли и возврата доступной margin;
- конкретные проценты и sizing могут изменяться;
- при повышении риска трейдер может вручную приблизить разгрузку;
- внешние новости/индикаторы в логике стратегии не используются.

## Правило публикации

Machine truth и trader explanation хранятся раздельно.

Подробные raw observations, event IDs, note IDs и реальные сделки относятся к исследовательскому/private dataset и не должны автоматически попадать в публичную GitBook документацию.

Публичный документ должен отвечать на вопрос «как работает механика», а не публиковать историю конкретного аккаунта.
