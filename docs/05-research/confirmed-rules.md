# Подтверждённые правила

**Статус: ПОДТВЕРЖДЕНО**

## 1. Объём задаётся в монетах

Основная единица размера — количество монет.

## 2. Сетка состоит из лимитных ордеров

Каждый Grid Order — лимитная заявка.

## 3. Первый ордер считается от Mark Price в момент запуска стратегии

Для Long первый уровень идёт ниже Mark Price, для Short — выше.

## 4. Следующий уровень считается по индивидуальному процентному отступу от предыдущей лимитной цены

Каждый Grid Order может иметь свой процент. Для расчёта следующего уровня не нужно ждать исполнения предыдущего.

## 5. Базовый способ задания уровней — проценты

На текущем этапе ручной ввод абсолютной цены не нужен как отдельный пользовательский режим.

## 6. Каждый ордер имеет собственные параметры

Отдельно задаются:
- процентный отступ;
- configured_qty;
- TP Steps.

## 7. Один ордер может исполниться несколькими частями

Несколько executions/fills из-за ликвидности не превращают его в несколько ордеров стратегии.

## 8. Расчёт разгрузки опирается на фактически исполненный объём

Если configured_qty = 1.0, но фактически исполнилось 0.3, то доля Take Profit считается от 0.3, а не от 1.0.

## 9. Take Profit считается от фактической средней цены конкретного Grid Order / Strategy Lot

Не от общей средней Long/Short позиции.

## 10. Take Profit выставляется реальными лимитными заявками

После появления фактически исполненного объёма система выставляет лимитные заявки на разгрузку. Для обычного TP в базовой стратегии Market не используется.

## 11. Сумма TP может быть меньше 100%

Трейдер сам решает, какую часть фактически исполненного объёма распределить по Take Profit.

## 12. На Bybit одновременно держится настраиваемое количество активных Grid Orders

Полная сетка может быть больше. По мере исполнения уровней система выставляет следующие, чтобы сохранять заданное количество активных лимитных заявок, например 3, 4 или 5.

## 13. Long и Short — отдельные сетки

Они работают зеркально относительно Mark Price, но конкретные параметры могут отличаться.

## 14. Каждый Grid Order является самостоятельной настраиваемой единицей

Будущие Take Profit и другие разрешённые параметры конкретного ордера можно менять через интерфейс в реальном времени.

## 15. Изменения управляемой стратегии выполняются через интерфейс платформы

Каждая правка сохраняется в истории Grid Revision.

## 16. Внешнее ручное вмешательство не запускает автоматическую перестройку

Сначала система уведомляет трейдера и ждёт подтверждения: принять новое состояние или восстановить прежнюю конфигурацию.

## 17. Внешние сигналы не используются

Не используются новости, sentiment, технические индикаторы, прогнозы аналитиков или AI price prediction.


## 18. Биржевые минимумы проверяются по параметрам инструмента Bybit

Перед размещением Grid Order система должна учитывать актуальные `minOrderQty`, `qtyStep`, `minNotionalValue` и `tickSize` конкретного инструмента. Эти ограничения зависят от монеты и не задаются одной общей константой для всех активов.
