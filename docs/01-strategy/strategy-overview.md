# Обзор стратегии

**Статус: ПОДТВЕРЖДЁННАЯ МЕХАНИКА + ОТКРЫТАЯ ЛОГИКА ПРИНЯТИЯ РЕШЕНИЙ**

## Что уже подтверждено

- стратегия работает с Long и Short в Hedge Mode;
- Long и Short ведутся как две отдельные сетки;
- Grid Orders — лимитные ордера;
- параметры каждого Grid Order задаются индивидуально;
- объём задаётся количеством монет;
- первый уровень рассчитывается от Mark Price в момент запуска;
- первый Long-уровень располагается ниже Mark Price, первый Short-уровень — выше;
- следующие уровни рассчитываются по индивидуальным процентным отступам от предыдущих лимитных уровней;
- один Grid Order может исполниться несколькими fills и всё равно остаётся одной логической единицей стратегии;
- после первого фактического исполнения у Grid Order появляется фактически набранный объём, который нужно учитывать отдельно от агрегированной позиции Bybit;
- Take Profit рассчитывается от фактической средней цены этого объёма;
- размер разгрузки рассчитывается от фактически исполненного объёма `filled_qty`;
- обычный Take Profit выставляется реальными лимитными заявками;
- на Bybit одновременно может поддерживаться только заданное активное окно Grid Orders, а остальная сетка хранится внутри платформы;
- каждый Grid Order можно индивидуально перенастраивать через интерфейс;
- все изменения конфигурации должны сохраняться как Grid Revision;
- внешние новости, sentiment, технические индикаторы и AI-прогнозы цены не используются.

## Что ещё не формализовано

- автоматическая формула sizing;
- автоматическая реструктуризация сетки;
- точная логика восстановления разгруженного объёма;
- точное использование realized PnL и available balance при реструктуризации;
- момент полного rebase сетки на новую Mark Price;
- Long/Short capital allocation как универсальная формула;
- combined break-even;
- Stop Loss;
- пороги и действия будущего Risk Manager.

## Архитектурное разделение

Стратегия теперь рассматривается как несколько независимых слоёв:

```text
Strategy Rules / Trader Configuration
        ↓
Base Grid Planner
        +
Restructuring Planner
        ↓
Risk Manager
        ↓
Execution Engine
        ↓
Bybit
```

Параллельно Recorder независимо фиксирует фактическую реальность Bybit.

**Decision layer** решает, что нужно сделать.  
**Risk layer** решает, допустимо ли это.  
**Execution layer** безопасно исполняет уже разрешённое действие.  
**Recorder** фиксирует, что реально произошло.
