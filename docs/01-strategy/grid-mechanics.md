# Механика сетки

**Статус: ПОДТВЕРЖДЁННАЯ БАЗОВАЯ МЕХАНИКА / ОТКРЫТЫЕ ПАРАМЕТРЫ**

## Ордера сетки

Ордера сетки (Grid Orders) — это **лимитные ордера (Limit Orders)**.

Для каждого уровня трейдер отдельно задаёт:
- цену или отступ;
- заданный объём в монетах (`configured_qty`);
- уровни Take Profit;
- долю закрытия на каждом уровне.

## Первый ордер

Первый Long-ордер ставится с отступом вниз от текущей Mark Price.

Первый Short-ордер ставится с отступом вверх от текущей Mark Price.

Конкретный процент отступа задаёт трейдер.

## Следующие уровни

Следующий ордер может рассчитываться от лимитной цены предыдущего ордера, не дожидаясь его исполнения.

Пример:

```text
Mark Price = 100
Long Order #1: -10% → 90
Long Order #2: -5% от 90 → 85.50
Long Order #3: -3% от 85.50 → 82.935
```

Проценты в примере не являются правилом стратегии.

## Объём

На текущем этапе объём каждого ордера задаётся **вручную отдельно**.

Автоматическая формула увеличения объёма пока не используется.

## Количество уровней

Количество ордеров в сетке задаётся конфигурацией. Маленький жёсткий лимит в модели данных не нужен.

## Изменение сетки

До исполнения лимитный ордер можно:
- передвинуть;
- изменить объём;
- отменить;
- удалить из текущей сетки.

После полного исполнения ордер уже нельзя «отменить»: фактическая сделка произошла, и дальше работа идёт с созданным Strategy Lot.

Случай частичного исполнения с последующей отменой остатка пока остаётся открытым вопросом.
