# Примеры (реальные данные)

**Статус: OBSERVED FACT** — все числа проверяемы по `orders` / `executions` / `closed_pnl` в рабочей БД Recorder'а. Полные записи с интерпретацией — в [05-research/trader-observations.md](../05-research/trader-observations.md) и `STRATEGY_KNOWLEDGE.md` в корне репозитория.

## Пример 1 — первый цикл Long по UAIUSDT (закрыт)

| Шаг | Ордер | Действие |
|---|---|---|
| Вход | `e50a9e55` | Buy 151 @ 0.331 — Filled |
| Grid #2 | `c750520e` | Buy 174 @ 0.287 (-13.3% от входа) — Cancelled |
| Grid #3 | `4d5d4bb4` | Buy 299 @ 0.234 (-29.3% от входа) — Cancelled |
| Выход | `04ccbb7c` | Sell 151 @ 0.385 reduceOnly — Filled |

Результат: полное закрытие (151 → 0), реализованный PnL **+8.1082285 USDT** (closed_pnl). Пояснение трейдера (verified): note #6 «Набор Лонга по активу uai», note #7 «Размещение Лонг ордеров до минус 30% от текущей цены». Цена выхода — ручное решение, не формула (со слов трейдера).

## Пример 2 — второй цикл Long по UAIUSDT (открыт на момент записи)

| Шаг | Ордер | Действие |
|---|---|---|
| Вход | `7d6f479b` | Buy 147 @ 0.34 — Filled |
| Grid #2 | `fe220964` | Buy 185 @ 0.27 (-20.6% от входа) — New |
| Grid #3 | `055cde98` | Buy 350 @ 0.2 (-41.2% от входа) — New |

Открыт через ~1 минуту после закрытия примера 1. Глубина сетки здесь **не совпадает** с примером 1 (-41.2% против -29.3%) — см. [05-research/contradictions.md](../05-research/contradictions.md).

## Пример 3 — открытие Short-сетки по UAIUSDT

| Ордер | Действие |
|---|---|
| `34c0c115` | Sell 104 @ 0.479 (+19.75% от цены ~0.40) — New |
| `857c033e` | Sell 106 @ 0.565 (+41.25%) — New |
| `7916db21` | Sell 89 @ 0.667 (+66.75%) — New |

Объёмы не растут монотонно с расстоянием (104 → 106 → 89), в отличие от наблюдавшихся Long-сеток. Объяснения трейдера по логике этой сетки пока нет.

## Что показывают эти три примера вместе

- Рост объёма глубже по сетке наблюдался дважды на Long, но с разными числовыми коэффициентами — недостаточно для формулы.
- Одна и та же формулировка трейдера («-30% от входа») дала разные фактические результаты в двух циклах — зафиксировано как противоречие, не сглажено.
- Short-сторона пока полностью не объяснена.
