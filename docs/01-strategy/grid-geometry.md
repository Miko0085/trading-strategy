# Геометрия сетки

**Статус: ПОДТВЕРЖДЁННЫЙ ПРИНЦИП / ОТКРЫТА ТОЧНАЯ ФУНКЦИЯ РАСПРЕДЕЛЕНИЯ**

Grid Geometry отвечает на вопрос: где расположены уровни относительно друг друга. Она не определяет объём ордеров.

## Входы

- количество уровней N;
- общая глубина сетки;
- отступ первого уровня;
- коэффициент распределения расстояний;
- сторона Long / Short;
- anchor/reference price.

## Geometry Vector

При старте Grid Cycle рассчитывается относительная структура уровней. Пока не произошло явного rebase или смены geometry policy, пропорции расстояний между уровнями сохраняются.

## Независимость механизмов

Geometry — форма сетки. Sizing — объёмы. Positioning / Trailing — положение сетки относительно рынка.

Изменение капитала может изменить qty без деформации geometry.

## Trailing

Trailing переносит anchor и вместе с ним неисполненную часть сетки, сохраняя относительную geometry. Уже исполненные Strategy Lots не перемещаются.

Точные trigger и step trailing остаются открытыми.
