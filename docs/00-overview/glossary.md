# Глоссарий

**Статус: TRADER EXPLANATION / CANDIDATE** (термины отражают текущее понимание механики, не финальную спецификацию)

| Термин | Значение |
|---|---|
| **Grid Order** | Лимитный ордер, часть сетки (Long или Short), выставленный на определённом расстоянии от предыдущего уровня. |
| **Strategy Lot** | Внутренняя единица учёта, создаваемая при фактическом исполнении Grid Order. Bybit агрегирует все исполнения в одну позицию по символу, но стратегия хранит lots отдельно, каждый со своей ценой входа и своим TP. См. [01-strategy/position-accounting.md](../01-strategy/position-accounting.md). |
| **original_qty** | Исходное количество монет в Grid Order / Lot на момент исполнения. Не меняется после закрытия части lot. |
| **remaining_qty** | Текущее оставшееся количество монет в lot после частичных закрытий. |
| **closed_qty** | Суммарное количество монет, уже закрытых по этому lot (частично или полностью). |
| **Execution** | Факт фактического исполнения ордера на бирже (Bybit execution). Отличается от статуса ордера `Filled` — см. [04-platform/bybit-integration.md](../04-platform/bybit-integration.md). |
| **Partial Take Profit (partial TP)** | Частичное закрытие lot на заданном расстоянии от цены входа lot, на заданный процент от `original_qty`. |
| **Partial unloading** | Практика частичной разгрузки позиции для фиксации realized PnL и высвобождения margin, без полного закрытия. |
| **Long Grid / Short Grid** | Две независимые сетки ордеров — по одной на каждую сторону в Hedge Mode. У каждой свои ордера, quantity, distances, TP, состояние. |
| **Hedge Mode** | Режим Bybit, при котором Long и Short позиции по одному символу существуют одновременно и независимо (positionIdx 1 = Long, 2 = Short, 0 = One-way). |
| **Reference / current price** | Цена, от которой считается первый уровень сетки при её построении. |
| **Spacing** | Расстояние (в %) между соседними уровнями сетки. Конфигурируемо, не хардкодится. |
| **Machine truth** | Факты, зафиксированные Recorder'ом напрямую с Bybit (ордера, исполнения, позиции, wallet) — не подлежат интерпретации. |
| **Trader reasoning** | Объяснение трейдера (текст/голос через Telegram), почему было выполнено действие — отдельный, не смешиваемый с machine truth слой. |

Технические сущности намеренно оставлены на английском, так как это имена полей в данных/коде.
