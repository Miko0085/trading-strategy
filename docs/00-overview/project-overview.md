# Обзор проекта

**Статус: OBSERVED FACT / TRADER EXPLANATION**

## Что это

Проект состоит из двух концептуальных слоёв.

### A. Recorder (существует, реализован)

Bybit Strategy Recorder — read-only система, которая записывает рыночные и аккаунт-события трейдера, торгующего вручную на Bybit: WebSocket (public/private), REST-сверку, RAW JSONL, нормализацию в SQLite, экспорт в Parquet, Telegram-интерфейс для голосовых/текстовых пояснений трейдера. Recorder **не размещает ордера** и не принимает торговых решений. Подробнее — [04-platform/recorder-role.md](../04-platform/recorder-role.md).

### B. Strategy / Platform documentation (эта папка, накопительная)

`docs/` — знание о самой торговой стратегии трейдера: механика (grid, Long/Short, Strategy Lots, partial TP), подтверждённые и гипотетические правила, открытые вопросы, будущий Risk Manager и execution platform.

## Зачем

Трейдер уже торгует вручную по системе, которая пока не полностью формализована (частично в его голове). Подход:

> Сначала наблюдаем реальное поведение (через Recorder) → документируем причины (через объяснения трейдера) → находим повторяющиеся закономерности → подтверждаем их у трейдера → только затем формализуем в алгоритм.

## Текущий статус

Проект **не является автономным торговым ботом**. Никакие внешние market indicators, новости или sentiment не используются как входные данные для решений (см. [principles.md](principles.md)). Formalization и тем более execution/Risk Manager — будущие фазы, см. [06-development/roadmap.md](../06-development/roadmap.md).
