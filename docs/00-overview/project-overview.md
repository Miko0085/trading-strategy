# Обзор проекта

**Статус: ПОДТВЕРЖДЁННАЯ АРХИТЕКТУРА / ИССЛЕДУЕМАЯ СТРАТЕГИЯ**

## Из чего состоит проект

Проект состоит из нескольких отдельных слоёв.

### 1. Recorder — запись фактических событий

Bybit Strategy Recorder — read-only система, которая записывает:
- рыночные события;
- ордера и исполнения;
- Long / Short позиции;
- состояние счёта;
- пояснения трейдера;
- историю событий.

Recorder ничего не размещает и не изменяет на бирже.

### 2. Execution Engine — исполнение настроенной механики

Отдельный компонент, который сможет механически исполнять настройки трейдера:
- сетку;
- объёмы;
- Take Profit;
- изменения через интерфейс.

Он не должен самостоятельно придумывать торговые решения.

### 3. Исследование стратегии

Мы одновременно сохраняем:
- что трейдер хотел сделать;
- что он настроил;
- что реально произошло на Bybit;
- почему он принял решение;
- какой получился результат.

Это нужно для последующей формализации реального алгоритма.

### 4. Будущий Risk Manager

Отдельный будущий слой, который будет контролировать риск капитала и позиции по подтверждённым правилам.

## Текущий статус

Проект ещё не является автономной торговой системой. Базовая механика формализуется, а неизвестные правила продолжают исследоваться.

Внешние индикаторы, новости и sentiment не используются как вход для торговых решений.
