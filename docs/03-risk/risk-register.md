# Реестр рисков

**Статус: ИССЛЕДОВАНИЕ / БУДУЩИЙ RISK MANAGER**

Этот список не является набором торговых правил. Он фиксирует классы рисков, которые позже нужно формализовать.

## Риски стратегии и позиции

1. Перекос между Long и Short.
2. Слишком большая суммарная позиция.
3. Накопление большого объёма по сетке.
4. Риск увеличения объёма глубже по сетке.
5. Исчерпание доступной маржи.
6. Ликвидация.
7. Большая просадка капитала без ликвидации.
8. Ошибочное использование нереализованной прибыли как доступного бюджета.
9. Разворот цены после добавления противоположной стороны.
10. Отсутствие ожидаемого отскока.
11. Актив долго не восстанавливается.
12. Резкий рост цены против Short.
13. Зависимость результата от траектории цены.
14. Частые резкие движения туда-обратно.
15. Плохая агрегированная средняя цена.
16. Ловушка усреднения.
17. Цена долго не достигает Take Profit.
18. Частичное исполнение ордера.
19. Несимметричное исполнение Long и Short.
20. Проскальзывание.
21. Недостаточная ликвидность.
22. Большой спред.
23. Влияние собственного ордера на рынок.
24. Funding.
25. Комиссии.
26. Иллюзия прибыли по отдельным закрытиям при плохом результате по общей equity.
27. Долгая блокировка капитала.
28. Изменение характера волатильности.
29. Концентрация капитала в одном активе.
30. Корреляция между активами.
31. Ошибка параметров.
32. Недостаточный запас капитала.
33. Риск масштабирования при увеличении счёта.
34. Экстремальное редкое движение рынка.
35. Делистинг или фактическая смерть токена.
36. Недоступность биржи.
37. Риск контрагента / биржи.

## Технические риски

38. Ошибка API или WebSocket.
39. Устаревшее состояние в системе.
40. Дублирование события.
41. Отклонение ордера биржей.
42. Задержки.
43. Ошибка программного обеспечения.
44. Ошибка восстановления после перезапуска.
45. Ошибка формализации стратегии.
46. Скрытое правило трейдера не попало в алгоритм.
47. Реальные ручные решения трейдера отличаются от формальной модели.
48. Переобучение на ограниченной истории.
49. Нереалистичный backtest / simulation.
50. Отсутствие независимого аварийного слоя риска.

## Главные темы для следующего исследования

- использование положительного Short uPnL при добавлении Long;
- запас капитала и доступной маржи;
- зависимость стратегии от отскока;
- худшая траектория цены;
- хвостовой риск увеличения объёма;
- «мертвый» актив / экстремальный рост против Short;
- максимально допустимая просадка;
- скрытые защитные правила трейдера.

Точные пороги и автоматические действия пока не подтверждены.
