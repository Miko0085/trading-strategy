# Жизненный цикл ордера

**Статус: НАБЛЮДАЕМЫЙ ФАКТ / ТЕХНИЧЕСКАЯ МЕХАНИКА**

## Состояния биржевой заявки

Типовые состояния Bybit:

```text
Новый (New)
→ Частично исполнен (PartiallyFilled)
→ Полностью исполнен (Filled)

Новый (New)
→ Отменён (Cancelled)

Новый (New)
→ Отклонён (Rejected)
```

Условные ордера могут также иметь состояния ожидания и срабатывания.

## Критическое правило

**Состояние ордера не равно фактическому исполнению.**

Один ордер может иметь несколько фактических исполнений (Execution / Fill).

Поэтому:
- `Filled` — это итоговый статус заявки;
- фактический объём и цена сделки берутся из execution-событий;
- несколько fills одного Grid Order не создают несколько логических ордеров стратегии.

## Что можно делать до полного исполнения

До полного исполнения лимитную заявку можно:
- изменить;
- передвинуть;
- изменить объём;
- отменить.

## После полного исполнения

После `Filled` отменить ордер уже нельзя: сделка произошла. Дальнейшее управление относится уже к Strategy Lot и его закрытиям.

Случай частичного исполнения с последующей отменой остатка пока остаётся открытым вопросом.
