# Grid Lifecycle

**Статус: CANDIDATE** (последовательность наблюдалась один раз целиком, повторения не подтверждены)

## Наблюдавшийся цикл (UAIUSDT, Long, см. примеры 1–2)

```
1. Открытие базового ордера (вход)
2. Выставление дополнительных Grid Orders ниже (для Long) / выше (для Short)
3. [опционально] Отмена части Grid Orders трейдером, без исполнения
4. Полное закрытие позиции одним reduceOnly-ордером
5. Почти сразу — открытие нового цикла от новой текущей цены
```

Это наблюдалось **один раз** от начала до конца (пример 1 → пример 2 в [01-strategy/examples.md](../01-strategy/examples.md)) — недостаточно для `CONFIRMED`.

## Не подтверждено

- Является ли шаг 5 (немедленное открытие нового цикла) правилом или совпадением конкретного случая.
- Что происходит с grid, если позиция не закрывается полностью, а разгружается частично (partial unloading) — не наблюдалось ни разу в текущем dataset.
- Явный триггер перестройки (см. [05-research/open-questions.md](../05-research/open-questions.md), вопрос 3).
