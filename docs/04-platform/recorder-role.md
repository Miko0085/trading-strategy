# Роль Recorder

**Статус: НАБЛЮДАЕМЫЙ ФАКТ**

Recorder — уже реализованный компонент проекта.

## Что делает Recorder

Recorder фиксирует:
- рыночные и аккаунт-события Bybit;
- ордера и исполнения;
- Long / Short позиции;
- кошелёк;
- изменения состояния;
- текстовые и голосовые пояснения трейдера;
- единую временную шкалу событий;
- данные для последующего анализа.

## Чего Recorder не делает

Recorder **никогда не торгует**.

В нём не должно быть:
- размещения ордеров;
- изменения ордеров;
- отмены ордеров;
- закрытия позиции;
- изменения leverage;
- выставления TP/SL.

Для Recorder используется только отдельный read-only API key.

## Два источника информации

```text
Фактическое состояние (Machine Truth)
= данные Bybit

Объяснение трейдера (Trader Reasoning)
= почему трейдер совершил действие
```

Эти слои хранятся отдельно.

## Главная исследовательская цепочка

```text
Состояние до действия
→ контекст рынка и счёта
→ действие трейдера
→ ордера
→ фактические исполнения
→ состояние после
→ объяснение трейдера
→ финансовый результат
```

Цель Recorder — позволить точно восстановить эту цепочку.
