# Интеграция с Bybit

**Статус: РЕАЛИЗОВАНО В RECORDER**

## Каналы данных

- **Публичный WebSocket (Public WebSocket)** — рыночные данные.
- **Приватный WebSocket (Private WebSocket)** — ордера, исполнения, позиции, кошелёк.
- **REST API** — сверка, восстановление, история и backfill.

Recorder использует только GET/read-only запросы.

## Ключевые правила

1. **Execution — факт исполнения.** Статус ордера `Filled` сам по себе не заменяет данные исполнения.
2. Сырой ответ Bybit сохраняется до нормализации.
3. Дедупликация выполняется в нормализованном слое, а не удалением raw-данных.
4. Один ордер может иметь несколько executions.
5. Перед запуском приватного Recorder проверяется, что API key read-only.
6. После reconnect выполняется сверка состояния.

## Источник истины по API

Используется только актуальная официальная документация Bybit V5.
