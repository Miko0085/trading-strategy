# Project Documentation

Основные документы проекта:

- `PROJECT_INSTRUCTIONS.md` — основной контекст: что строим, зачем, архитектурные принципы и границы текущего этапа.
- `DEVELOPMENT_RULES.md` — правила для Codex/AI-разработчика и требования к реализации.
- `STRATEGY_KNOWLEDGE.md` — отдельная база знаний о самой торговой стратегии: факты, объяснения, гипотезы и подтверждённые правила.

Перед внесением существенных изменений в проект разработчик/AI должен сначала прочитать `PROJECT_INSTRUCTIONS.md` и `DEVELOPMENT_RULES.md`.
