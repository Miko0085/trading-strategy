# Project Documentation

Основные документы проекта:

- `PROJECT_INSTRUCTIONS.md` — основной контекст: что строим, зачем, архитектурные принципы и границы текущего этапа.
- `DEVELOPMENT_RULES.md` — правила для Codex/AI-разработчика и требования к реализации.
- `STRATEGY_KNOWLEDGE.md` — накопительный журнал наблюдений по стратегии: факты, объяснения, гипотезы, подтверждённые правила (сырой шаблонный формат, по одной записи на событие).
- `docs/` — структурированная, публикуемая через GitBook каноническая документация стратегии и платформы (обзор, механика, алгоритм, риски, research, roadmap). См. [`docs/README.md`](docs/README.md).

Перед внесением существенных изменений в проект разработчик/AI должен сначала прочитать `PROJECT_INSTRUCTIONS.md`, `DEVELOPMENT_RULES.md` и `docs/README.md`.
