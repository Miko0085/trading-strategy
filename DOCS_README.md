# Документация проекта

Основные документы:

- `PROJECT_INSTRUCTIONS.md` — общий контекст и архитектурные границы проекта.
- `DEVELOPMENT_RULES.md` — правила разработки.
- `DEVELOPMENT_STATUS.md` — технический статус **только Recorder**, а не Execution Engine.
- `STRATEGY_KNOWLEDGE.md` — исследовательские заметки и накопление знаний.
- `docs/` — каноническая публичная документация стратегии и платформы, публикуемая через GitBook.

Основной язык документации — русский.

Технические названия полей, API и сущностей кода могут оставаться на английском, но пользовательские разделы и объяснения должны быть понятны русскоязычному трейдеру.

Все Markdown-файлы хранятся в UTF-8.
